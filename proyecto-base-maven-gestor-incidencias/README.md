# README a completar

## Nombre, finalidad y descripción breve del proyecto;
Gestionar la creacion y resolucion de diferentes incidencias junto con posibles errores
## Versión de java que utiliza
17
## listado de funcionalidades que permite realizar la aplicación;
Crear una incidencia, mostrar todas las incidencias, mostrar las incidencias abiertas
mostrar las incidencias que coincidan con el teto introducido y buscar una incidencia por su identificador.
## compilación y ejecución;
Hay un menu con 5 opciones de acciones que elegir, depende de cuál elijas haces una acción diferente
## generación y consulta de Javadoc;
El javadoc se almacena en la carpeta docs para que asi github pages la encuentre y lo genere sin errores ni inconvenientes
## una tabla con las clases principales y su responsabilidad general.
| Clase| Responsabilidad |
| :--- | :---: |
| Incidencia | Modelo para crear una incidencia|
| GestorIncidencias | Gestiona una lista de incidencias, las busquedas y mostrar incidencias |
| IncidenciaNoEncontradaExcepcion | Gestiona los errores de busqueda de GestorIncidencias |
## estructura de archivos
Todas las clases se encuentran en la carpeta incidencias, la ultima carpeta dentro del src
